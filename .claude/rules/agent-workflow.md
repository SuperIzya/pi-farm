# Required Agent Workflow

- Always use SocratiCode when working on this project. Follow its applicable
  skills, check index status before searching, and use semantic search and
  dependency tools to understand the code and the impact of changes. Use `rg`
  for exact identifiers and text matches.
- Always apply the Ponytail skill at **full** level unless the user explicitly
  changes the level or disables it. Make the smallest complete change, reuse
  existing code, and verify changes with appropriate checks.
- If either required skill or tool is unavailable, report that limitation
  explicitly instead of silently skipping it.
